# LDL (SM89 SASS)

**NVIDIA:** Load within Local Memory Window (Load/Store Instructions). Source: [CUDA Binary Utilities, Ampere/Ada instruction set](https://docs.nvidia.com/cuda/cuda-binary-utilities/index.html#nvidia-ampere-gpu-and-ada-instruction-set)

Notes: Load from local memory (register spills) (category: Load / store)

Typically emitted for: `ld.local`; register spills, local arrays with dynamic indexing

## Evidence

Checked with Build cuda_12.9.r12.9/compiler.36037853_0 (`-arch=sm_89`) and nvdisasm (Build cuda_13.4.r13.4/compiler.38855100_0); see [verify/RESULTS.md](../verify/RESULTS.md).

Claimed lowering confirmed by probe(s):

- [ldl_stl](../verify/RESULTS.md#ldl_stl): `dynamically indexed .local array`

Encodings: <https://kuterdinel.com/nv_isa_sm89/LDL.html> (machine-derived by fuzzing the assembler; no semantics).
